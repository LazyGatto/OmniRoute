- **fix(usage):** release the captured provider request body when its dispatch settles — the `Capture` object created by `createPreparedRequestLogger` (`open-sse/utils/providerRequestLogging.ts`) is held in an `AsyncLocalStorage` store, so sockets and streams created during dispatch keep it alive long after the request finishes; its `latest` field kept the full serialized request body (3–10 MB for vision traffic with base64 images) reachable forever. `runWithCapture()` now calls the new optional `Capture.release()` in its `finally`, dropping the retained body as soon as the dispatch is over (the `body(fallback)` path already falls back to the transformed body).
